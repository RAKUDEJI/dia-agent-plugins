# dia plugin

This dual-manifest plugin supplies the `dia` Agent Skill to Codex and Claude Code, and connects the hosted dia MCP at `https://dia.sdweb.workers.dev/mcp`. Version `0.1.0-next.6`.

**The skill carries no copy of dia's vocabulary.** dia derives its own reference from its own schemas and serves it — `diagram://reference/*`, `diagram://examples/*`, one `diagram://diagnostics/{code}` per code it can emit, the JSON Schemas, and the same set over HTTP at `GET /api/v1/docs` — so the skill points at that and states only what the server cannot: how to choose between the hosted MCP and a local project, the working loop, and the discipline. It used to ship `references/cli.md`, `tsx-authoring.md` and `remote-mcp.md`; they went stale exactly as a copy does, teaching `validate_tsx` after the tool became `check_tsx`, `dia validate` for a CLI whose command is `check`, and `idScope` after it was removed. `scripts/validate.mjs` now asserts the absence of those words and of those files.
