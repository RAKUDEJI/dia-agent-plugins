# dia plugin

This dual-manifest plugin supplies the `dia` Agent Skill to Codex and Claude Code. It uses the public `@rakudeji/dia` CLI and does not include an MCP server or external service.

The skill is located at `skills/dia/SKILL.md` and its detailed CLI and TSX guidance is self-contained under `skills/dia/references/` so marketplace installations do not depend on files outside the plugin.
